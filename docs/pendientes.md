# Pendientes según la rúbrica

| Pieza | Estado | Qué falta |
|---|---|---|
| Manifiesto (200–300 palabras) | Borrador en la página | Que el grupo lo lea, lo edite y quite la etiqueta «Borrador» |
| Entrevista (3–5 min) | Pendiente | Grabarla, consentimiento informado, subir el enlace |
| Encuesta (≥ 5 personas, a favor y en contra) | Pendiente | Crear el formulario (ver `encuesta-propuesta.md`), pegar el enlace |
| Videoensayo (1–3 min) | Pendiente | Producirlo y subirlo |
| Glosario (5–6 conceptos con bibliografía) | Borrador en la página | Verificar definiciones y referencias contra las lecturas |
| Mínimo 2 extras | Línea de tiempo, «Dos versiones» y Chasqui (chat de preguntas frecuentes) ya hechos | Confirmar con el profesor si cuentan como extras |
| Reflexión escrita (800–1000 palabras + bibliografía) | Pendiente | Se entrega en Paideia, no va en la página |
| Autoevaluación (rúbrica adjunta) | Pendiente | Llegó sin el adjunto |
